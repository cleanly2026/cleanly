Create `apps/customer-mobile/app/orders/[orderId]/tracking.tsx` (Screens 7 + 8, RT-02, RT-03, D-04, D-05, D-06):

**Route:** Dynamic route `[orderId]` extracts order ID from params. Also receives `customerLat`, `customerLng`, `serviceType`, `orderType` ('on_site' | 'carpet') via route params or fetched from API.

**Hook integration:**
```typescript
const { washerLocation, washerInfo, orderStatus, connected } = useOrderTracking(orderId, token)
const { etaMinutes } = useEta(washerLocation?.lat ?? null, washerLocation?.lng ?? null, customerLat, customerLng)
```

**State-based rendering:**

a) **Loading state (connected === false or washerLocation === null):**
- Skeleton: washer avatar circle + 2 text line skeletons in bottom sheet area. Shimmer animation: left-to-right gradient, 1.2s loop.

b) **Tracking state (orderStatus is `washer_en_route` or `pickup_scheduled` or `out_for_return`):**
- Full-screen `<MapView>` occupying entire viewport (flex: 1).
- Provider: Google Maps on Android (default), Apple Maps on iOS.
- `<WasherMarker>` with current washer location.
- Customer location pin: gold pin at destination using `<Marker>` with gold-colored custom View.
- Map auto-fits both markers: `mapRef.current?.fitToCoordinates([washerCoords, customerCoords], { edgePadding: { top: 100, right: 50, bottom: 300, left: 50 } })` on first location update.

**Floating top bar:** Absolutely positioned, translucent navy (`rgba(26, 39, 68, 0.9)`), rounded bottom corners 12px. Height: 56px + safe area top inset. Contains:
- Back arrow (Lucide `ChevronLeft`, white) — navigates back
- Order number (monospace, 14px label, white)
- Status badge (pill shape, color per status — gold for en_route, green for in_progress)

**TrackingBottomSheet** at bottom — passing washer info, ETA, and status label. Status label logic:
- `washer_en_route` + on_site: `tracking.onTheWay`
- en_route + carpet (check if order flow is pickup phase): `tracking.pickingUp`
- en_route + carpet (return phase): `tracking.delivering`

c) **In-progress state (orderStatus is `in_progress`):**
- Replace entire map with `<InProgressCard>`.
- Floating top bar still visible.
- No bottom sheet — InProgressCard is self-contained.

d) **Completed state (orderStatus is `completed`):**
- Full-screen centered layout. Background: `#F8F7F4` (brand.surface).
- Service-type-aware heading (20px heading, navy):
  - Car wash: "Your car is clean!" / "سيارتك نظيفة!" (`tracking.completeCar`)
  - Sofa: "Your sofa is clean!" / "أريكتك نظيفة!" (`tracking.completeSofa`)
  - Carpet: "Your carpets are clean and returned!" / "سجادك نظيف وتم إعادته!" (`tracking.completeCarpet`)
- Before/after photos (if available): side-by-side thumbnails, each 50% width, 160px height, 8px border-radius. "Before" / "After" labels below each (14px label, muted).
- "Rate your service" link (16px body, gold `#C9A84C`) — present but disabled (out of Phase 3 scope, disabled with opacity 0.5 and `onPress={() => {}}`)
- "Back to Home" button: navy bg, white text, 44px, full-width.

**i18n:** All text uses `useTranslation` with `tracking.*` keys.
**RTL:** `marginStart`/`marginEnd`. Map is direction-neutral. Text layout respects `I18nManager.isRTL`. Numeric amounts (order number) wrapped in `direction: 'ltr'` View.

**Map labels:** Pass language to MapView — for Google Maps provider, set `mapLanguage: i18n.language === 'ar' ? 'ar' : 'en'` via the `customMapStyle` or provider URL parameter per UI-SPEC I18N-06.
