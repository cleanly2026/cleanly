**NEON-SETUP.md (ACCT-03):**
- Dashboard: https://console.neon.tech
- CRITICAL: Neon has NO Bahrain region. Use ap-southeast-1 (Singapore) for lowest Gulf latency, or eu-central-1 (Frankfurt). Present both options — user decides during provisioning.
- Capture TWO URLs: pooled URL (contains `-pooler` in hostname) for DATABASE_URL, and direct URL (no `-pooler`) for DIRECT_URL.
- 1Password item: `Cleanly - Neon` with fields: `database_url_pooled`, `direct_url`, `password`
- Secrets go to: Fly.io (`DATABASE_URL`, `DIRECT_URL`), GitHub Environments (`NEON_DIRECT_URL` for CI migrations)
- Billing: Free tier (0.5 GiB, 5 compute hours/mo); set alert at 80% of compute hours

- 1Password item: `Cleanly - Upstash Redis` with fields: `connection_string`, `rest_url`, `rest_token`, `password`
- Secrets go to: Fly.io (`UPSTASH_REDIS_URL`, `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN`)
- Billing: Fixed $10/mo — set payment method, alert at $15/mo
