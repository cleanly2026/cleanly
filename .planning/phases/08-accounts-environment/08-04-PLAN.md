Set up GitHub Environments (staging + production) with CI-consumed secrets. Per D-08, GitHub Environments hold CI-only secrets: NEON_DIRECT_URL, SENTRY_AUTH_TOKEN, TURBO_TOKEN, TURBO_TEAM, FLY_API_TOKEN, VERCEL_TOKEN.

**Step 1: Authenticate GitHub CLI**
The user must run `gh auth login` and complete the browser OAuth flow. `gh` 2.88.0 is installed but not authenticated.

**Step 2: Create environments**
After auth, Claude runs:
```bash
gh api repos/{owner}/{repo}/environments/staging -X PUT --input - <<< '{}'
gh api repos/{owner}/{repo}/environments/production -X PUT --input - <<< '{}'
```
(Replace `{owner}/{repo}` with actual repo path from `gh repo view --json nameWithOwner -q .nameWithOwner`)

**Step 3: Set secrets per environment**
For each environment (staging and production), set the CI-only secrets. The user retrieves values from 1Password items created in Task 1:

```bash
# Staging
gh secret set NEON_DIRECT_URL --env staging --body "<value from 1Password: Cleanly - Neon > direct_url>"
gh secret set SENTRY_AUTH_TOKEN --env staging --body "<value from 1Password: Cleanly - Sentry > auth_token>"
gh secret set FLY_API_TOKEN --env staging --body "<value from 1Password: Cleanly - Fly.io > deploy_token>"
gh secret set VERCEL_TOKEN --env staging --body "<value from 1Password: Cleanly - Vercel > deploy_token>"

# Production (same secrets, potentially different values for NEON_DIRECT_URL)
gh secret set NEON_DIRECT_URL --env production --body "<value>"
gh secret set SENTRY_AUTH_TOKEN --env production --body "<value>"
gh secret set FLY_API_TOKEN --env production --body "<value>"
gh secret set VERCEL_TOKEN --env production --body "<value>"
```

Note: TURBO_TOKEN and TURBO_TEAM will be set after Vercel project linking (Phase 9), since the Turbo remote cache token comes from Vercel. Skip these two for now — document them as "set in Phase 9 after Vercel project linking."

**Step 4: Verify**
```bash
gh secret list --env staging
gh secret list --env production
```
Both should show NEON_DIRECT_URL, SENTRY_AUTH_TOKEN, FLY_API_TOKEN, VERCEL_TOKEN.
