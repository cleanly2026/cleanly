**Create `apps/api/src/lib/job-dispatch.ts`** (new file, per D-04):

Export a single function `registerJobDispatchHandlers(socket: Socket)` that registers two socket event handlers:

**`job:accept` handler:**
1. Extract `washerId` from `(socket as any).userId` — if missing, emit `socket.emit('job:error', { orderId, message: 'Not authenticated' })` and return
2. `const order = await prisma.order.findUnique({ where: { id: orderId } })` — if not found, emit `job:error` with `'Order not found'`
3. Verify `order.washer_id === washerId` — if mismatch, emit `job:error` with `'Not assigned to this order'`
4. Call `await transitionOrderStatus(orderId, OrderStatus.washer_en_route)` in try/catch — on error, emit `job:error` with the error message
5. Cancel BullMQ timer: `const timerJob = await orderQueue.getJob(\`washer-timeout-\${orderId}\`); if (timerJob) await timerJob.remove()`
6. Emit to company and customer rooms:
   ```
   const io = getIO()
   io.to(`company:${order.company_id}`).emit('order:status-changed', { orderId, status: 'washer_en_route' })
   io.to(`order:${orderId}`).emit('order:status-changed', { orderId, status: 'washer_en_route' })
   ```
7. Emit success back to washer: `socket.emit('job:accepted', { orderId })`

**`job:decline` handler:**
1. Same auth check as accept (steps 1-3)
2. Revert order per D-03: `await prisma.order.update({ where: { id: orderId }, data: { washer_id: null, status: 'accepted' } })`
3. Cancel BullMQ timer (same pattern as accept step 5)
4. Notify company: `io.to(\`company:\${order.company_id}\`).emit('order:status-changed', { orderId, status: 'accepted' })`
5. Emit success: `socket.emit('job:declined', { orderId })`
