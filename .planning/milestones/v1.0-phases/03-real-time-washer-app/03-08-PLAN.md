<objective>
Wire real auth tokens throughout all washer-mobile screens and fix the GPS userId gap.

Purpose: Root causes 1 and 2 from VERIFICATION.md. Every washer-mobile screen uses MOCK_TOKEN=null or token='', making all API calls no-ops or 401 failures. Additionally, useGpsTracking emits washer:join-order without userId, causing the server to drop all GPS location events. This plan creates an AuthContext that reads the JWT from AsyncStorage (stored by the washer login flow in Phase 1), provides it to all screens, and fixes the GPS join payload.

Output: All washer-mobile screens have real auth tokens; GPS location pipeline is unblocked end-to-end.
</objective>
