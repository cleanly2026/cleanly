**Create `apps/api/src/routes/company/packages.ts` (COMP-03):**

Full CRUD for packages and their add-ons. Follow the exact same pattern as profile.ts and services.ts for auth and companyId extraction. All prices in fils (integer). Bilingual fields required via Zod schema.

Export a function named `companyPackageRoutes` (matches the import name in the original 02-05 plan).

Endpoints:
1. `GET /` — List all packages for company. `prisma.package.findMany({ where: { company_id: companyId! }, include: { add_ons: true }, orderBy: { created_at: 'desc' } })`. Return `{ packages }`.

2. `POST /` — Create package. Schema: `packageSchema`. Create with `prisma.package.create({ data: { company_id: companyId, category: body.category, name_en: body.name_en, name_ar: body.name_ar, description_en: body.description_en, description_ar: body.description_ar, base_price: body.base_price } })`. Return 201.

3. `PUT /:id` — Update package. Schema: `packageSchema`. Verify ownership with `prisma.package.findFirst({ where: { id, company_id: companyId! } })`. Return 404 if not found. Update same fields.

4. `DELETE /:id` — Soft delete. Verify ownership. Set `is_active: false`. Return `{ success: true }`.

5. `POST /:id/add-ons` — Create add-on. Schema: `addOnSchema`. Verify package ownership. `prisma.addOn.create({ data: { package_id: packageId, name_en: body.name_en, name_ar: body.name_ar, price: body.price } })`. Return 201.

6. `DELETE /:id/add-ons/:addOnId` — Soft delete add-on. Verify package ownership. Set `is_active: false`. Return `{ success: true }`.

Import path for schemas: `import { packageSchema, addOnSchema } from '@cleanly/types'`
Import path for prisma: `import { prisma } from '../../lib/prisma.js'`

**Create `apps/api/src/routes/company/washers.ts` (COMP-04):**

Export a function named `companyWasherRoutes`.

Endpoints:
1. `GET /` — List washers. `prisma.user.findMany({ where: { company_id: companyId!, role: 'washer' }, select: { id: true, phone: true, created_at: true, washer_profile: { select: { is_online: true } } }, orderBy: { created_at: 'desc' } })`. Return `{ washers }`.

2. `POST /` — Create washer account. Schema: `washerSchema`. Check duplicate phone with `prisma.user.findUnique({ where: { phone: body.phone } })` — return 409 if exists. Hash default PIN "0000" with bcryptjs (import as `import bcrypt from 'bcryptjs'` — per decision, bcryptjs not bare bcrypt). Create user with `prisma.user.create({ data: { role: 'washer', phone: body.phone, company_id: companyId, pin_hash: defaultPinHash, washer_profile: { create: {} } } })`. Return 201 with `{ id, phone }`.

3. `PATCH /:id/deactivate` — Deactivate washer. Verify ownership with `prisma.user.findFirst({ where: { id, company_id: companyId!, role: 'washer' } })`. Return 404 if not found. Set `company_id: null` (per decision — removes from roster without deleting user). Return `{ success: true }`.

Import path for schema: `import { washerSchema } from '@cleanly/types'`
