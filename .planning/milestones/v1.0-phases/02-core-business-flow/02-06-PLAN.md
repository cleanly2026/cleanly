**Create `apps/customer-web/app/[locale]/booking/on-site/page.tsx` (Screens 4, BOOK-01 to BOOK-04, D-05):**

`'use client'` page. Single scrollable page per D-05.

- Read URL search params: `package` (package_id), `company` (slug)
- Fetch company profile via TanStack Query to get package details and add-ons
- Section order per D-05: package summary -> add-ons (AddOnChips) -> location (LocationPicker via `next/dynamic` with `ssr: false`) -> access notes -> order summary (BookingSummary)
- Local state: `selectedAddOns: string[]`, `location: { lat, lng }`, `locationNote: string`, `quantity: number`
- Running total computed client-side for display: `(package.base_price * quantity) + sum(selected add-on prices)` + `platform_fee_estimate = Math.round(subtotal * 0.15)` (estimate, actual computed server-side)
- StickyBottomBar with running total and "Book Now" CTA
- CTA disabled until: package selected AND location pinned (D-05 interaction contract)
- On CTA click: POST `/orders/on-site` with `{ package_id, quantity, add_on_ids, service_location, location_note }`
- On success: navigate to `/payment?order_id={order_id}&client_secret={client_secret}`
- On error: show error toast

Quantity selector: numeric stepper (minus/count/plus buttons), 44px touch targets, `dir="ltr"` on the stepper container (numeric input always LTR).

**Create `apps/customer-web/app/[locale]/payment/page.tsx` (Screen 6, PAY-01, D-09, D-10, D-11):**

`'use client'` page. Reads `order_id` and `client_secret` from URL search params.

- Load Stripe with `loadStripe(process.env.NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY!)`
- Wrap in `<Elements stripe={stripePromise} options={{ clientSecret, locale: locale === 'ar' ? 'ar' : 'en', appearance: { theme: 'flat', variables: { colorPrimary: '#C9A84C' } } }}>`
- Render `<PaymentElement />` inline, full-width, no card wrapper (UI-SPEC)
- Fetch order summary from API: `GET /orders/{order_id}` (to display price breakdown above payment)
- BookingSummary component above PaymentElement showing the order details
- "Confirm & Pay AED X.XX" CTA button: full-width, `bg-brand-gold text-brand-navy`, 52px height (larger per UI-SPEC)
- On click: `stripe.confirmPayment({ elements, redirect: 'if_required', confirmParams: { return_url: '${origin}/${locale}/booking-confirmed?order=${orderId}' } })`
- On error: inline error text below PaymentElement — `text-semantic-destructive` body size, `t('booking.payment_failed')` (D-11: no modal, no toast, inline only)
- On success: redirect to booking-confirmed page
