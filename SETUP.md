# Cleanly — Developer Setup

## Prerequisites

- Node.js 20+ (LTS)
- pnpm 9.x (`npm install -g pnpm`)
- 1Password CLI (`op`) — [Install guide](https://developer.1password.com/docs/cli/get-started/)
- Access to the "Cleanly" 1Password vault

## Quick Start

1. Clone the repo and install dependencies:
   ```bash
   git clone <repo-url>
   cd cleanly
   pnpm install
   ```

2. Authenticate with 1Password CLI:
   ```bash
   op signin
   ```

3. Bootstrap all environment files from 1Password:
   ```bash
   pnpm setup:env
   ```
   This runs `op inject` for every app, producing:
   - `apps/api/.env`
   - `apps/customer-web/.env.local`
   - `apps/admin-web/.env.local`
   - `apps/company-web/.env.local`
   - `apps/customer-mobile/.env`
   - `apps/washer-mobile/.env`
   - `packages/db/.env`

4. Start the development servers:
   ```bash
   pnpm dev
   ```

## Without 1Password CLI

If you don't have access to 1Password CLI, copy the `.env.example` files manually:

```bash
cp apps/api/.env.example apps/api/.env
cp apps/customer-web/.env.example apps/customer-web/.env.local
cp apps/admin-web/.env.example apps/admin-web/.env.local
cp apps/company-web/.env.example apps/company-web/.env.local
cp apps/customer-mobile/.env.example apps/customer-mobile/.env
cp apps/washer-mobile/.env.example apps/washer-mobile/.env
cp packages/db/.env.example packages/db/.env
```

Then fill in real values from the provider dashboards. See `docs/accounts/` for per-provider setup guides.

## Environment Files

| File | Purpose | Committed? |
|------|---------|------------|
| `.env.example` | Documentation with fake values | Yes |
| `.env.op.tpl` | 1Password template with `op://` references | Yes |
| `.env` / `.env.local` | Real secrets (generated by `op inject`) | No (gitignored) |

## Provider Accounts

Setup guides for each third-party service are in `docs/accounts/`:
- Neon PostgreSQL, Upstash Redis, Twilio, Resend, Sentry
- Cloudflare R2, Fly.io, Vercel, Expo EAS, Google Play
- 360dialog (WhatsApp), Stripe (deferred), Apple Developer (deferred)
